## 1. 这是什么？一句话说清

**DeepSeek 肥鱼娘桌宠，是一只住在你 Windows 电脑桌面上的小鲸鱼拟人少女。**

她不是一张静态壁纸，而是一个**活的**小东西：

- 她会**呼吸**（身体轻轻起伏）、会**眨眼**、会**摆尾巴**、偶尔头顶**喷水**；
- 她会**饿**（饱食度会掉）、会**困**（精力会掉）、会**想你**（太久不理她会难过）；
- 你可以**摸摸她的头**、**喂她小鱼干**、**陪她玩**、**让她睡觉**；
- 她会**自己说话**（内置 65 类、1127 句中文台词），也会**自己走动**；
- 你还能**跟她聊天**（接入 DeepSeek AI 接口，像和一个有性格的小伙伴对话）；
- 她会**做梦**、会**记事情**、会**有心里话**、会**慢慢长大**，甚至还有**三魂七魄**和**修真层**（道行、五脏六腑、因果、业、缘……）。

她住在你的桌面上，不占地方，不抢焦点，你干活她就在旁边待着。

**一句话**：这是一个**会陪你、会成长、会说话**的桌面小伙伴，形象是你自己的鲸鱼娘，声音可以是你自己录的。

## 3. 三十秒上手：装上就能用

### 3.1 你需要什么

- **Windows 10 或 Windows 11**（64 位）
- 如果从源码运行：**Python 3.10+**
- 大约 200 MB 磁盘空间（含素材）
- 可选：一个 DeepSeek API Key（想聊天才需要）

### 3.2 两种安装方式

**方式 A：直接跑打包好的 exe（最简单）**

1. 拿到 `build_output\DeepSeekFishPet.dist\` 整个目录；
2. 把 `大肥鱼素材表\`、`鲸宝形象\`、`鲸宝音频\`、`mahjong\`、`数字\` 这几个目录**放到 exe 旁边**（同一个目录里）；
3. 双击 `DeepSeekFishPet.exe`。

**方式 B：从源码运行（开发/折腾用）**

1. 装 Python 3.10+；
2. 安装依赖：`pip install PySide6 requests`；
3. 双击 `1.bat`（或者命令行运行 `python DeepSeekFishPet.py`）。

### 3.3 第一次启动会看到什么

1. 一个**启动画面**（带进度条，几秒钟）；
2. 然后桌面上出现一个**小鲸鱼少女**（默认在屏幕正中）；
3. 她会**说一句话**（启动台词，比如「我来啦，今天也一起加油吧！」）；
4. 右下角托盘出现一个**小图标**（找不到桌宠时点它就能唤回来）。

就这样，**已经能用了**。

## 4. 桌面上会出现什么

### 4.1 桌宠本体

一个**无边框、透明背景、可以拖动**的小窗口。默认大小约 220×260 像素。

- 她**不抢焦点**：你点别的窗口，她不会跳出来；
- 她**默认置顶**（可以在设置里关）；
- 你**看不见她的窗口边框**，只有那个小鲸鱼。

### 4.2 头顶的昵称牌（可选）

默认**关闭**。打开后头顶会显示一个小牌子，写着你对她的称呼（默认「肥鱼娘」）。

### 4.3 说话气泡

她说的话会出现在头顶的一个**圆角小气泡**里，几秒后自动淡出。

- 气泡宽度、字号、停留时间都能调；
- 泡泡太多可以整个关掉。

### 4.4 系统托盘图标

右下角任务栏里的小图标。

- **左键/双击**：显示或隐藏桌宠；
- **右键**：弹出和桌面右键**完全一样**的菜单。

## 5. 六种玩法

### 5.1 摸头（最简单）

**把鼠标放到她身上，点一下左键。**

- 心情 +6、亲密度 +2、经验 +3；
- 她会说一句「被摸头」的话（比如「嘿嘿…摸摸头真舒服～」）；
- 摸够多次会变成别的反应（亲密度够高时，25% 概率变成撒娇）。

### 5.2 投喂

**右键 → 🐾 互动 → 🐟 投喂小鱼干。**

- 饱食 +28、心情 +7、亲密度 +1、经验 +6；
- 她会做一个「吃东西」的动作，说一句投喂台词；
- 吃饱了再喂，她会说「已经吃饱啦」。

**喝水**是另一个入口（右键 → 🐾 互动 → 💧 喝点水）：饱食 +6、心情 +3。

### 5.3 玩耍

**双击她**（或者在菜单里点 🎮 陪它玩）。

- 心情 +10、精力 -8、亲密度 +3、经验 +12；
- 她会跳舞（转圈动画）；
- 累了（精力低）会不太想玩。

### 5.4 睡觉

**右键 → 🐾 互动 → 😴 睡觉 / 叫醒。**

- 睡着后画的是「蜷成一团」那张新形象图；
- 睡着期间精力会**快速恢复**（默认每小时 +12）；
- 再点一次叫醒，她会伸懒腰。

**自动作息**：设置里打开「到点自动睡觉 / 自动醒来」，设定入睡和起床小时，她会自己睡自己醒。

### 5.5 聊天

**按 `Ctrl+O`，或者在右键菜单点 💬 聊天…**

- 打开一个聊天窗口（和普通聊天软件差不多）；
- 打字、回车发送；
- 她会**一个字一个字**地回复（流式输出）；
- 回复完她会**念一句**（可以把回复截断成一句话放在气泡里）。

**需要 API Key 才能聊天。** 没有 Key 也能打开聊天窗口，但只能看到「离线模式」提示——她会用内置台词敷衍你。

### 5.6 看着它（什么都不做）

有时候最好的玩法就是**什么都不做**，看着她：

- 她会**自己走动**（默认每 45 秒换一个位置）；
- 她会**自己说话**（默认每 120 秒一句）；
- 她会**自己做小动作**（默认每 30 秒）；
- 她会**做梦**（睡觉醒来时，距上次做梦够久就复述一段梦）；
- 她会**说心里话**（灵魂系统，默认每 45 分钟）。

这些全都能在设置里调间隔或关掉。

## 6. 常见疑问（第一次用的人最想问的 20 个问题）

**Q1：她要钱吗？**
不用钱。程序本身免费（MIT 开源）。只有你**主动接入 DeepSeek AI 聊天**时，才会消耗你自己的 API 额度。

**Q2：她会偷看我的东西吗？**
不会。她不联网（除非你在聊天），不读你的文件，不记录你的按键。数据全部存在 `pet_data\` 目录里，**只有你能看到**。

**Q3：她为什么不动？**
检查三件事：① 设置里「动画帧率」是不是被调到很低；② 她是不是睡着了（睡觉时动作会变慢）；③ 她是不是正处于「等待/忙碌」状态形象。

**Q4：我怎么把她关掉？**
右键 → ❌ 退出程序，或者按 `Ctrl+Q`。托盘图标右键也有退出。

**Q5：她跑了怎么办（拖到屏幕外看不见了）？**
按 `Ctrl+Alt+C`，或者托盘右键 → 🪟 窗口 → 🎯 回到屏幕中央。她一定会回来。

**Q6：我不想让她一直置顶，挡我看东西。**
设置 → 🎨 外观 → 取消「总是显示在最前面」。

**Q7：怎么让她小一点？**
滚轮往下滚，或者设置里调「大小倍数」（0.35× ~ 3.0×）。

**Q8：怎么让她透明一点？**
设置 → 🎨 外观 → 不透明度（0.15 ~ 1.0）。

**Q9：她说的话我不想看，能关吗？**
设置 → 🎨 外观 → 取消「允许说话气泡」。

**Q10：她的声音能关吗？**
设置 → 🎨 外观 → 声音组里取消「启用形象声音」，或者右键菜单 → 🐋 形象 → 🔊 声音开关。

**Q11：我能给她改名字吗？**
设置 → 🎨 外观 → 昵称。改完立刻生效（窗口标题、名牌都跟着变）。

**Q12：她能换颜色吗？**
能。设置 → 🎨 外观 → 配色方案（5 套：深海蓝/樱粉/薄荷青/晚霞橙/夜航紫）。但注意：这个只在**代码绘制模式**下生效，用素材表形象时颜色是图里定好的。

**Q13：我能换她的形象吗？**
能。设置 → 形象素材 → 基础形象（正面 / 背面 / 侧面）。想换一整套就替换 `鲸宝形象\` 目录里的图。

**Q14：她的声音能换成我自己的吗？**
能，而且**推荐这样做**。把录音放进 `鲸宝音频\` 目录，按类别命名（`voice_poke_1.mp3` 这种），程序会自动优先用你的录音。详见第三部第 27 章。

**Q15：她不说话只有气泡，怎么回事？**
可能原因：① 声音总开关关了；② 那一类语音你没录、素材包也没有；③ 系统没有音频设备。**气泡照旧会显示**，只是没声音。

**Q16：数据存哪儿？我想备份。**
全部在 `pet_data\` 目录（程序目录下；如果程序目录不可写，会在 `%APPDATA%\DeepSeekFishPet\pet_data\`）。里面有设置文件、数据库、日志、备份、导出。

**Q17：换电脑怎么搬？**
把整个程序目录（含 `pet_data\`、`大肥鱼素材表\`、`鲸宝形象\`、`鲸宝音频\`、`.env`）复制过去就行。

**Q18：她会不会越用越占空间？**
日志会轮转（单文件 2 MB、留 5 份），备份会按份数清理（默认留 10 份），状态采样会按天数清理（默认 90 天）。基本不会无限增长。

**Q19：我能同时开两只吗？**
不能。程序是**单实例**的——第二次启动会把已有的那只**叫出来**，而不是开第二只。

**Q20：我不想要她了，怎么彻底删掉？**
关掉程序，删掉整个程序目录（记得先看一眼 `pet_data\` 里有没有你想留的东西）。她不写注册表（除了托盘图标退出时自动清理），不留系统痕迹。

## 10. 它会自己做的事

### 10.1 自己走动

默认每 45 秒换一个位置。她会：
- 转身（朝向移动方向）；
- 播放「走路」动作（身体上下浮动 + 轻微倾斜）；
- 走到目标后停下。

**关掉**：设置 → 🎮 行为 → 取消「自己走来走去」。

### 10.2 跟随鼠标

打开后，光标离她远时她会**朝你游过去**（很黏人）。

**打开**：设置 → 🎮 行为 → 勾上「跟着鼠标跑」。

### 10.3 自言自语

默认每 120 秒说一句话。说什么由**当前状态**决定：

- 饿了 → 说「饿」的话
- 累了 → 说「累」的话
- 心情低 → 说「难过」的话
- 太久没理 → 说「想你」的话
- 关系亲近 + 心情好 → 30% 概率撒娇
- 都不满足 → 按时段问候（早上/中午/下午/傍晚/夜里）

### 10.4 自己做小动作

默认每 30 秒做一个动作。可能是挥手、蹦跳、转圈、坐下、吃东西等。

### 10.5 做梦

睡着醒来时，如果距离上次做梦够久（默认 6 小时），她会**复述一段梦**。

梦的骨架从 `大肥鱼素材表\梦境.json` 读，有 15 种情绪、316 句。梦里会出现**真实数据**：
- 「N 只手」（她被摸了多少次）
- 「3 条小鱼干」（今天吃了几条）
- 「Lv5 的刚认识的小鱼」（她的称号）
- 「今天玩的那 2 次」
- 「认识 30 天这件事」
- ……

### 10.6 说心里话（灵魂）

默认每 45 分钟自己找你说一句。优先级：
1. **攒着的心事**（她之前憋着没说的）
2. **关系升级感言**（刚变得更亲时）
3. **里程碑回忆**（第一次见面、被摸最多的一天……）
4. **日常心声**（按关系阶段分档）

### 10.7 三魂七魄与修真层

这两层是**慢演化**的：
- 三魂七魄的**灵气只涨不跌**（摸头、投喂、陪玩、睡觉都养魂），跨过「旺（≥75）/ 弱（≤35）」门槛她会专门说一句；
- 修真层的**道行也只升不降**（池鱼 → 逐浪 → 吞云 → 化鲸 → 过龙门 → 乘云 → 登仙），跨段会说一句「突破」。

## 11. 让它说话：离线台词库与语音

### 11.1 台词从哪来

台词分三层：

1. **内置台词库**（写在代码里，52 类 486 句，程序删了 JSON 也能说话）；
2. **`大肥鱼素材表\台词库.json`**（程序优先读它，65 类 1127 句）；
3. **你新加的类别**（在 JSON 里加就行，只要有人调用它就会被说出来）。

### 11.2 怎么加一句台词

1. 用记事本打开 `大肥鱼素材表\台词库.json`；
2. 找到你想加的类别（比如 `"greet"`）；
3. 在那个数组里加一行：`"新的一句台词",`
4. 保存；
5. 右键菜单 → 🧰 工具 → 📜 重新载入台词库。

**立即生效，不用重启、不用重新编译。**

### 11.3 语音从哪来

语音的优先级：
1. **你自己录的**（`鲸宝音频\` 目录里的 `voice_<类别>_<序号>.mp3`）；
2. **素材包自带的**（素材4 / 素材6，**默认退役**，要手动开）。

**自己录的永远优先。**

### 11.4 怎么录自己的声音

1. 看 `大肥鱼素材表\录音清单.md`（照着勾的作业单，一期 106 条）；
2. 用手机或电脑录音，每条存成 `voice_<类别>_<序号>.mp3`（如 `voice_poke_1.mp3`）；
3. 放到 `鲸宝音频\` 目录（可以按类别分子目录，如 `鲸宝音频\poke\voice_poke_1.mp3`）；
4. 重启程序，或者右键菜单 → 🔄 重新扫描素材表。

**录了就会自动用，没录的类别照旧出声（或者不出声）。**

### 11.5 语音台词从哪来

语音文件本身**没有任何文字信息**（mp3 里没有 ID3 标题/备注）。台词要么：
- 你自己录的时候顺便写进 `鲸宝音频\语音台词.json`；
- 或者程序从素材清单的 `voices[].text` 读（人工听写）。

## 13. 它会饿会困：四条属性与衰减

### 13.1 四条属性

| 属性 | 默认衰减 | 说明 |
| --- | --- | --- |
| 心情 | 2.0 /小时 | 互动会涨，太久不理会掉 |
| 饱食 | 4.0 /小时 | 投喂会涨，饿了会喊 |
| 精力 | 3.0 /小时 | 睡觉会恢复（默认 +12/小时） |
| 亲密度 | 0.5 /小时 | **超过 60 后不再衰减** |

### 13.2 关掉程序也算

如果你关掉程序 8 小时再打开，她会**补算这 8 小时的衰减**。所以回来时可能看到她很饿很困。

### 13.3 会说话

- 饱食 ≤25 → 说「饿」的话；
- 精力 ≤22 → 说「累」的话；
- 心情 ≤25 → 说「难过」的话；
- 太久没理（>6 小时）→ 说「想你」的话。

### 13.4 不想让她饿

三种办法：
1. 设置里把衰减速度调低（甚至可以调成 0）；
2. 用**内置修改器**把数值拉满并**锁定**；

## 16. 算番：手机也能用的国标麻将算番器

### 16.1 这是什么

一个**国标麻将算番器**，跑在你的电脑上，但**手机/平板也能用**（同一个 WiFi 下浏览器打开）。

### 16.2 怎么用

1. 桌宠启动时会自动把算番 Web 服务打开（默认端口 8718）；
2. 打开算番窗口（右键菜单 → 🧰 工具 → 🀄 算番 Web 版…，或者设置 → 🀄 算番）；
3. 复制「手机 / 平板」那一行的地址；
4. 在手机浏览器里打开那个地址；
5. 在手机上算番（选牌、点计分）；
6. **桌宠会把总番数读出来**（用 `数字\` 目录里的音频）。

### 16.3 读番规则

- 会念成「合计 + 数字 + 番」；
- 105 → 「一百零五」（如果 `数字\零.mp3` 存在）；
- 没有「零」会读成「一百五」（自己补一个 `零.mp3` 就正了）；
- 连点算番时**不打断**：停手 0.9 秒才念最后一次。

### 16.4 需要什么文件

- `mahjong\` 目录（4 件套）；
- `数字\` 目录（数字音频）。

缺了也不会崩，只是算番/读番功能不可用。

### 20.1 位置

### 20.2 结构

```json
{
  "_说明": "以 _ 开头的键是说明，程序会忽略",
  "mode": "replace",
  "drop_missing": false,
  "lines": {
    "greet": ["主人回来啦！", "早呀主人～"],
```

### 20.3 字段详解

| 字段 | 取值 | 说明 |
| --- | --- | --- |
| `mode` | `replace` / `merge` | `replace`（默认）：这里出现的类别**整个取代**内置；`merge`：追加到内置后面（按内容去重） |

| `lines` | 对象 | 类别 → 句子数组；句子**必须是字符串** |
| 顶层简写 | — | 不写 `lines` 包裹也行，直接 `{ "greet": ["…"] }` |
| 类别名 | 自由 | 可自由新增（`_` 开头忽略） |
| `level_titles` | 可选 | `[[等级, 称号], …]`（整个替换内置表） |
| `time_greetings` | 可选 | `[[起始小时, 结束小时, 类别], …]`（整个替换内置表） |

## 38. AI 客户端与线程模型

```
主线程                QThreadPool              worker 线程
  │                       │                       │
  ├─ dfp_send() ─────────►│                       │
  │                       ├─ DFPDeepSeekWorker ──►│
  │                       │                       ├─ dfp_chat()
  │                       │                       │
  │◄─ 信号（排队回主线程）─┤◄──────────────────────┤
  │  dfpReplyChunk        │                       │
  │  dfpReplyDone         │                       │
```

- `QRunnable` 本身不能带信号；
- 所以信号放在独立的 `DFPDeepSeekSignals`（`QObject`）里；
- worker 通过它发信号，Qt 自动排队回主线程。
