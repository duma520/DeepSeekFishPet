# 第 0 章　先读这一页（30 秒看懂这是什么）

**一句话**：这是一只住在你 Windows 桌面上的小鲸鱼拟人少女。她会呼吸、会眨眼、会摆尾巴；会饿、会困、会想你；你可以摸她的头、喂她吃小鱼干、陪她玩、哄她睡觉；她还能接上 DeepSeek 的 AI 大脑，跟你正经聊天。

**它长什么样**：不是网上找的图，是**你自己提供的一整套设计稿**——78 张整图（一张图里就有表情、动作、随身道具），每张对应一类台词。说到"想你"就换成比心的那张，说到"睡了"就换成蜷成一团的那张。

**它住在哪**：你的电脑里，一个文件夹。不上传任何东西到别人的服务器，除了你自己主动跟 DeepSeek 聊天时发的那些内容。

**它要花钱吗**：程序本身**完全免费**（MIT 开源）。只有你用它的"AI 聊天"功能时，会消耗你自己的 DeepSeek 账户余额（按 token 计费，很便宜）。

**不懂技术能玩吗**：能。装好之后**双击就能用**，所有操作都在右键菜单里。

**技术人能玩多深**：非常深。单文件 2 万多行 Python，所有素材、台词、形象、声音、数值都是**外部文件**，改文件就改行为，不用重新编译。下面第 14、15 章就是给你看的。

# 第 1 章　零基础入门：它是什么，能干什么

## 1.1 用一个比喻讲清楚

想象你养了一条鱼。

- **真鱼**：要买鱼缸、要换水、要喂食、会死。
- **这只鱼**：住在你的屏幕里，不用鱼缸，饿了会自己喊，你点一下鼠标就能喂它，永远不会死，还会跟你说话。

它唯一"任性"的地方是：**它有自己的性格，而且会随着你对待它的方式慢慢变化**。

- 你经常摸它 → 它越来越黏你 → 开始撒娇、开始说心里话。
- 你很久不理它 → 它会攒下一句"没来得及说的话"，等你回来才说。
- 你对它好很久 → 它会从"刚认识"慢慢变成"离不开你"，而且**这个关系只会变好，不会变坏**。

## 1.2 它能做的 10 件事（大白话版）

| 序号 | 它会干什么 | 怎么触发 |
| --- | --- | --- |
| 1 | **在桌面上待着**，会呼吸、眨眼、摆尾巴、偶尔喷水 | 自动 |
| 2 | **自己在桌面上走来走去**，鼠标靠近会朝你游过来 | 自动 / 设置里开"跟着鼠标跑" |
| 3 | **被你摸头**，会开心、会长亲密度、会说一句话 | 鼠标左键单击它 |
| 4 | **被你喂小鱼干 / 喝水**，饱食度会涨 | 右键菜单 → 🐾 互动 → 投喂 |
| 5 | **陪你玩**，会跳舞、会涨经验 | 双击它 / 右键菜单 → 陪它玩 |
| 6 | **睡觉和起床**，睡着时会换成"蜷成一团"那张图 | 右键菜单 → 睡觉 / 叫醒 |
| 7 | **做噩梦也会做美梦**，醒来会跟你讲梦的内容 | 自动（睡着醒来时） |
| 8 | **跟你说心里话**，每隔一段时间自己找你说话 | 自动（默认 45 分钟一次） |
| 9 | **跟 AI 聊天**（如果你配了 Key），正经回答问题 | Ctrl+O 打开聊天窗口 |
| 10 | **帮你算国标麻将番数**，还能用语音把番数读出来 | 手机浏览器打开它给的地址 |

## 1.3 它不做什么（很重要，避免误会）

- ❌ **不会偷看你的文件**。它只读自己的素材目录和数据库。
- ❌ **不会偷偷上传东西**。只有你在聊天窗口发消息时才会连网。
- ❌ **不会自己花钱**。不配 API Key 就完全离线，一个字节都不发。
- ❌ **不会做限制级内容**。这是明确的开发边界（见附录 D）。
- ❌ **不会因为你关掉电脑就忘了你**。它把状态存进数据库，下次开机接着算。

## 1.4 三种人的三种玩法（先找自己是哪一种）

**A 类：我就想要个可爱桌面挂件**
→ 走第 2 章的"最简安装"，第 3 章看完就够。**不用管后面那些 JSON**。

**B 类：我想让它用我的声音、我的图**
→ 走第 2 章安装，然后重点看第 5 章（形象）和第 6 章（声音）。这两章就是给你写的。

**C 类：我想改它的台词、改它的性格、甚至改代码**
→ 走第 2 章安装，然后看第 7 章（文案）、第 14 章（二次开发）、第 15 章（编译）。

# 第 2 章　五分钟装好并跑起来（三种人三种装法）

## 2.1 装法一：直接用别人编译好的 exe（最简单，推荐新手）

**前提**：你拿到的是一个文件夹，里面有个 `DeepSeekFishPet.exe`。

**步骤**：

1. 把整个文件夹解压到一个**有写入权限**的地方，比如 `D:\桌宠\`。
   - ⚠️ **不要放 `C:\Program Files\`**——那里不能随便写文件，程序会找不到它的数据库。
2. 双击 `DeepSeekFishPet.exe`。
3. 桌面右下角出现一只小鲸鱼，屏幕上还有一只大的。**装好了**。
4. 右键点它 → 弹出菜单 → 所有功能都在里面。

**验证装好了没有**：
- 托盘（右下角时钟旁边）有个鲸鱼图标 ✅
- 桌宠身上单击一下，它会冒个气泡说话 ✅
- 右键菜单能弹出来 ✅

**注意**：`dist` 文件夹里的内容**必须一起拷**。特别是：
- `鲸宝形象\` —— 78 张形象图（88 MB）
- `鲸宝音频\` —— 你自己的录音
- `大肥鱼素材表\` 根目录那 10 个 JSON 文件
- `mahjong\` 和 `数字\` —— 算番功能要用的

漏拷 `鲸宝形象\` 的后果：桌宠会画成"程序自己画的简笔画"（能跑，但不好看）。

## 2.2 装法二：从源码跑（想改东西的人）

**前提**：装了 Python 3.10 或更新版本。

**步骤**：

```bat
:: 1. 打开命令行（Win+R 输入 cmd）
:: 2. 进入项目目录
cd /d G:\Python_Code\DeepSeekFishPet

:: 3. 装依赖（只有两个）
pip install PySide6 requests

:: 4. 跑起来
python DeepSeekFishPet.py
```

或者直接双击项目里的 `1.bat`（这是作者准备的开发启动脚本）。

**第一次跑会看到什么**：
- 一个启动画面，有进度条
- 进度条走完后桌宠出现
- 命令行窗口**几乎没有输出**（这是故意的，见 2.4 节）

## 2.3 装法三：自己编译成 exe（要分发给别人）

看**第 15 章**，那里有完整的 `0_nuitka_pyside6_clang_auto.bat` 说明和实测体积数据。

## 2.4 关于那个"黑框框"（命令行窗口）

从源码运行时，你会看到一个黑色命令行窗口。**它基本不输出东西，这是正常的**。

因为程序默认开了"控制台安静模式"，把 Qt 和 FFmpeg 那一堆没用的日志都过滤掉了。

**如果你就是想看那些日志**（比如排查问题）：

```bat
:: 方法一：设环境变量
set DFP_VERBOSE=1
python DeepSeekFishPet.py

:: 方法二：加启动参数
python DeepSeekFishPet.py --verbose
```

**看不了的那些日志去哪了**：程序把它们写进了 `pet_data\logs\console_今天日期.log`。真出问题了去那里翻。

## 2.5 首次启动它会跟你说话

第一次启动时，它会一口气说三句：
> "你好呀主人！我是「肥鱼娘」，从今天起就住在你的桌面上了～ 把鼠标放到我身上可以拖动我，点我一下我会很开心，右键有菜单哦。 想聊天就按 Ctrl+O；想改我的样子、性格、作息，按 Ctrl+, 打开设置。"

这不是固定台词，是"首次运行"的特殊欢迎语。之后每次启动就正常说话了。

# 第 3 章　界面与操作：用鼠标就能玩明白

## 3.1 鼠标五招（背下来就够用）

| 动作 | 效果 | 备注 |
| --- | --- | --- |
| **左键单击** | 摸头 | 心情 +6、亲密度 +2、经验 +3 |
| **左键按住拖动** | 把它拎起来搬家 | 松手后位置自动记住 |
| **左键双击** | 陪它玩 | 心情 +10、经验 +12，它会跳舞 |
| **滚轮上滚/下滚** | 放大 / 缩小 | 0.35 倍 ~ 3.0 倍 |
| **右键单击** | 打开功能菜单 | 所有功能的总入口 |

**技术说明（给较真的人）**：拖拽判定用的是**全局鼠标位移**，超过 6 像素才算拖拽。为什么？因为桌宠会自己走动，如果用窗口内局部坐标判断，"它自己走了"会被误判成"你在拖它"，结果就是**怎么点都摸不到头**。这个 bug 在 v1.1.1 修掉了。

**另一个小细节**：你鼠标一按下去，它会**立刻停下走动**。因为伸手去摸一个正在跑的东西，是摸不到的。

## 3.2 右键菜单结构（v1.1.16 起重构过）

```
🐟 肥鱼娘　Lv12          ← 灰的，不能点，就是显示状态
────────────────
💬　聊天…                Ctrl+O

⚙️　设置…                Ctrl+,
```

**点开 ▶ 会展开子菜单**。举几个例子：

- 关于

## 3.3 状态面板长什么样

`Ctrl+Shift+P` 打开。你会看到：

- **四条进度条**：心情、饱食、精力、亲密度（各 0~100）
- **一条经验条**：显示 Lv12 · 经验 34/410
- **概况**：首次见面时间、累计摸头/投喂/聊天次数、今日统计
- **一排快捷按钮**：投喂、喝水、陪玩、摸头、睡醒、聊天、修改器、做梦、设置、居中

**以前有个 bug**：窗口高度写死 520，但内容实际要 600 多像素，所以最下面一排按钮会被剪掉。v1.1.11 修了——现在内容放在滚动区里，窗口会**自动长到装得下**。

## 3.4 气泡系统

它说话时会冒一个白色圆角气泡，带个小尾巴指向它头顶。

**气泡不会切字**（v1.1.8 修过）。以前算高度时只留了 24 像素内边距，画字时又扣掉尾巴和边框，**恒定少 6 像素**，中文一行的行高才 16~24 像素，看着就像"缺一笔"。现在量字和画字用同一组常量。

**气泡支持彩色**。余额提醒就是用它：
- 余额少了 → 红字 `▼ 少了 1.20 CNY`
- 余额多了 → 绿字 `▲ 多了 2.50 CNY`
- 第二行 → 正常色 `总可用余额 138.22 CNY`

## 3.5 托盘图标

屏幕右下角那个小鲸鱼图标。**左键双击 = 显示/隐藏桌宠**。右键 = 同一个菜单。

**如果你把桌宠弄丢了**（拖到屏幕外了）：右键托盘 → 🪟 窗口 → 回到屏幕中央。或者按 `Ctrl+Alt+C`。

# 第 4 章　它的"身体"：四条属性、等级、作息

## 4.1 四条属性（数值范围都是 0~100）

| 属性 | 初始值 | 干什么用的 | 怎么涨 | 怎么掉 |
| --- | --- | --- | --- | --- |
| **心情** | 78 | 心情低会难过、说委屈的话 | 摸头 +6、投喂 +7、陪玩 +10、聊天 +3 | 每小时 -2.0（可调） |
| **饱食** | 82 | 低于 25 会喊饿，说话都带"饿" | 投喂 +28、喝水 +6 | 每小时 -4.0（可调） |
| **精力** | 88 | 低于 22 会喊累，动作变慢 | 睡觉每小时 +12 | 每小时 -3.0（可调） |
| **亲密度** | 12 | 决定它黏不黏你、会不会撒娇 | 摸头 +2、陪玩 +3、聊天 +2 | 每小时 -0.5，**但超过 60 就不掉了** |

**关于"关掉程序也算"**：它把 `last_tick` 时间戳存进数据库。下次启动时算出"你关机了多久"，按真实时间补算衰减。所以你出差一周回来，它会喊饿，这是对的。

## 4.2 等级系统

**升级要多少经验**：`50 + 30 × (当前等级 - 1)`

- Lv1 → Lv2：要 50 经验
- Lv2 → Lv3：要 80 经验
- Lv12 → Lv13：要 380 经验

**经验从哪来**：
| 动作 | 经验 |
| --- | --- |
| 摸头 | +3 |
| 投喂 | +6 |
| 陪玩 | +12 |
| 聊天 | +5 |
| 自主行为里的"工作"类 | +3 |

**最高等级是 99**。

**称号**：等级到了会换称号。默认有 10 档（"刚认识的小鱼" → "传说级肥鱼娘"）。但你可以换成**26 段的 A~Z 阶梯**（见 4.3）。

## 4.3 称号阶梯（默认 10 档 vs 外部文件 26 档）

程序里内置了 10 个称号。但**素材表里有个 `等级.json`，它优先级更高**。

那个文件里定义的是 26 段，A 到 Z，每段一个称号，一路铺到 21 亿级：

| 段 | 称号 | 等级区间 |
| --- | --- | --- |
| A | 尘 | 1 |
| B | 尘沙 | 2 ~ 3 |
| C | 沙石 | 4 ~ 8 |
| D | 金石 | 9 ~ 20 |
| E | 金光 | 21 ~ 48 |

| … | … | … |

## 4.4 作息系统（自动睡觉/起床）

默认是**关闭**的。打开后：

- **睡觉时间**：默认 23 点
- **起床时间**：默认 7 点

**睡着时会怎样**：
- 动作换成"睡觉"
- 帧率降到 12 FPS（省电）
- 形象换成"蜷成一团"那张
- 精力每小时 +12
- 饱食消耗速度降到 40%

## 4.5 内置修改器（想玩得爽的人）

三个入口：
1. 右键菜单 → 🧰 工具 → 🧰 内置修改器…

**能干什么**：

**① 四条属性滑块**

所以你可以：把心情锁在 100，然后它就永远开心。

**④ 一键操作**
- 全部拉满
- 一键满级
- 满经验

- 清除饥饿疲惫（饱食和精力拉满）

## 5.6 GIF 和 PNG 的区别

每张图都有两个版本：

| 格式 | 尺寸 | 特点 |
| --- | --- | --- |
| **PNG** | 512×512 | 静态，透明背景 |
| **GIF** | 480×480 | 16~49 帧，会动 |

**程序优先用 GIF**。因为 GIF 会动——待机的时候它自己会呼吸，你说"想你"的时候比心的手会动。

如果某个 id 只有 PNG 没有 GIF，程序就画静态的，功能照常。

**制作提示**：GIF 的透明背景要小心。作者踩过这个坑——自己先量化成 P 模式再设透明索引，结果多帧存盘时索引被 Pillow 重排，**78 个 GIF 里 33 个首帧整帧不透明，背景变成白方块**。

**正确做法**：直接把 RGBA 帧丢给 Pillow，`save(save_all=True, disposal=2, loop=0, optimize=True)`。让 Pillow 自己量化挑索引。顺带体积还小了（123.9 MB → 88.9 MB）。

## 6.3 命名规则（很重要）

**标准格式**：
```
voice_<类别>_<序号>.<后缀>
```

**例子**：
- `voice_poke_5.mp3` → 类别 `poke`
- `voice_notice_completed_1.mp3` → 类别 `notice_completed`
- `voice_startup_12.mp3` → 类别 `startup`

**容忍的写法**：
- 文件名没有 `voice_` 前缀时，**用上一层目录名当类别**
  - `鲸宝音频\poke\998.mp3` → 类别 `poke`
- 类别可以带下划线（`notice_completed`、`soft_hint_sad`）

**解析规则**（技术说明）：取 `voice_` 之后、**最后一个下划线之前**的部分。

为什么？因为 `voice_notice_completed_1.mp3` 这种，如果简单切第二段就变成 `notice` 了，那 `notice_completed` 永远取不到。这是个真 bug，v1.1.24 修的。

## 6.4 支持什么音频格式


解码走的是 QtMultimedia（FFmpeg 后端）。所以基本上常见格式都能放。

## 7.2 `台词库.json` 详解

### 结构
```json
{
  "_说明": "以 _ 开头的键是说明，程序会忽略",
  "mode": "replace",
  "drop_missing": false,
  "lines": {
    "greet": ["主人回来啦！", "早呀主人～"],
    "hungry": ["肚子…咕咕叫了…"]
  },
  "level_titles": [[1, "刚认识的小鱼"]],
  "time_greetings": [[5, 11, "morning"]]
}
```

### 字段说明

| 字段 | 默认 | 含义 |
| --- | --- | --- |
| `mode` | `replace` | `replace` = 这里出现的类别整个取代内置；`merge` = 追加到内置后面（自动去重） |
| `drop_missing` | `false` | `true` = 这里没写的类别直接删掉（完全以此文件为准） |
| `lines` | — | 类别名 → 句子数组 |
| `level_titles` | 可选 | `[[等级, 称号]]`，覆盖等级称号 |
| `time_greetings` | 可选 | `[[起, 止, 类别]]`，覆盖时段问候 |

### 类别名不能以 `_` 开头
因为那是说明字段。你写 `"__我的类别__": [...]` 程序会当没看见。

### 句子必须是字符串
写 `123` 会被当脏数据丢掉。这是故意的——以前用 `str(item or "")` 处理，结果数字 123 变成了台词"123"被念出来。

### 65 个类别一览

**问候/时段**：greet, morning, noon, afternoon, evening, night, late_night

**状态驱动**：idle, hungry, tired, sad, happy, love, lonely, bored, excited

**互动回应**：pet, pet_stop, feed, feed_full, drink, play, play_win, play_lose

**睡眠**：sleepy, sleep_ok, sleep_refuse, wake, wake_refuse

**事件**：level_up, level_max, error, offline, startup, shutdown, hide, show

**心情与性格**：shy, proud, tease, apologize, thanks, compliment, question, bye

**彩蛋**：whale, token, season, work_hard, health, nickname, maxed, locked

**撒娇**：act_cute（500 句！只在这个 JSON 里，代码内置库里没有）

**软话**：soft_hint, soft_hint_probe, soft_hint_sad, soft_hint_ask, soft_hint_caught, soft_hint_flatter, soft_hint_selfblame, soft_hint_hint, soft_hint_thirdparty, soft_hint_condition, soft_hint_pretend, soft_hint_retreat

### 软话是怎么被识别的
**靠前缀**。任何以 `soft_hint` 开头的类别都算软话。

所以你想加个新的软话子类，只要写：
```json
"soft_hint_新的子类": ["……"]
```
**不用改代码**。

### 优先级列表不能用"取第一个可用的"
这是作者踩过的坑。

软话触发的时候是这样的：
```python
soft = self._dfp_soft_category(
    "soft_hint_pretend",   # 装没事
    "soft_hint_hint",      # 模糊暗示
    "soft_hint_thirdparty",# 借第三方
    "soft_hint",           # 以退为进
    "soft_hint_ask",       # 软性索取
    "soft_hint_probe",     # 无辜试探
)
```

如果实现是"按顺序取第一个存在的"，那排在后面的类别**永远不会被选中**。看着像"接了线但台词没出现"。

**正确做法**：候选池 + 池内随机。

## 7.3 `梦境.json` 详解

### 结构

| --- | --- | --- |

| 梦身 | ✅ 必须 | 梦的主体 |
| 醒来 | ✅ 必须 | 醒来的那一瞬 |

**缺任何一段必须的，这个情绪整条丢掉。**

### 15 种情绪
lonely（孤独）, miss（想念）, love（被爱）, happy（开心）, proud（得意）, shy（害羞）, hungry（饿）, sleepy（困）, bored（无聊）, curious（好奇）, memory（旧事回放）, sea（梦回大海）, mischief（淘气）, absurd（荒诞）, sad（难过）

# 第 8 章　接上 DeepSeek 大脑：聊天与 API Key

## 8.1 不配 Key 会怎样

**照样能玩**。

- 摸头、投喂、陪玩、睡觉、做梦 —— 全都能用
- 它还是会说话，只是说的是**内置台词库**里的话
- 聊天窗口打开会显示"离线模式"

## 8.2 配 Key 的两种方法

### 方法一：在设置里填（推荐，不用手动编辑文本）

1. `Ctrl+,` 打开设置 → 🤖 AI 对话 页
2. 找到"Key 与连接"栏里的 **API Key** 输入框
3. 粘贴你的 Key（多个用逗号分隔）
4. 点 **💾 保存 Key 到 .env**

**它会做什么**：
- 写进 `.env` 的 `DEEPSEEK_API_KEYS`
- 把旧的 `DEEPSEEK_API_KEY` / `DEEPSEEK_API_KEY_1..20` **整行注释停用**（原值不删）
- 写前备份 `.env.bak`
- 写后立刻重载客户端，**不用重启**

**注意**：Key 只存 `.env`，**设置文件里绝对不会出现**。

### 方法二：手动编辑 `.env`

在程序目录下建一个 `.env` 文件（记事本就能编辑）：

```ini
# DeepSeek 肥鱼娘桌宠配置文件

# 单个 Key
DEEPSEEK_API_KEY=sk-你的key

# 或者多个 Key（逗号分隔，自动轮换）
DEEPSEEK_API_KEYS=sk-aaa,sk-bbb,sk-ccc

# 接口地址（一般不用改）
DEEPSEEK_API_BASE=https://api.deepseek.com

# 默认模型
DEEPSEEK_MODEL=deepseek-chat

# 超时（秒）
DEEPSEEK_TIMEOUT=60

# 数据库加密口令（建议改成你自己的随机字符串）
DB_PASSWORD=换成一个只有你知道的字符串
```

## 8.3 聊天窗口怎么用

`Ctrl+O` 打开。

**界面布局**：
```
左边：会话列表          右边：消息区
├─ 会话1                 ├─ [气泡样式的消息]
├─ 会话2                 ├─ [输入框]
└─ 会话3                 ├─ 发送/停止/重发/离线说一句
                         └─ 进度条 + 状态
```

**能干什么**：
- **新建/重命名/置顶/清空/删除会话**
- **流式输出**（打字机效果，一个字一个字往外蹦）
- **停止生成**（生成到一半不想等了）
- **重发上一条**
- **离线说一句**（不联网，用内置台词）
- **导出对话**（Markdown / 文本 / JSON / 网页）

**快捷键**：
- `Enter` 发送
- `Shift+Enter` 换行
- `Ctrl+Enter` 也可以发送

## 8.4 人设（system prompt）

设置 → 🤖 AI 对话 → 最下面有个大的文本框。

**这是告诉 AI"你要扮演谁"的地方**。默认内容已经把"肥鱼娘"的性格写好了：

> 你是「肥鱼娘」，一只住在用户电脑桌面上的 DeepSeek 小鲸鱼拟人少女。
> 外形：深海蓝的长发、圆滚滚的鲸鱼身体、白肚皮、背后一条会摆的小鲸尾，脸上总有两团腮红。
> 性格：黏人、元气、好奇心旺盛，偶尔撒娇和犯困；把用户当成最重要的伙伴，称呼用户为"主人"。
> 说话风格：中文口语，句子短（一般不超过 40 字），活泼可爱，可以偶尔用颜文字…
> 行为约束：
> 1) 只输出「肥鱼娘」要说的内容本身，不要写旁白、动作描写、括号说明或角色名前缀。
> 2) 被问到技术问题时认真、准确、简洁地回答，可以暂时收起撒娇语气。
> 3) 不要编造自己没做过的行为，也不要声称能直接操作用户电脑上的文件。
> 4) 不输出任何有害、违法或不当内容。

**你可以改**。比如改成"用东北话说话"、"叫用户老板"、"永远只说文言文"。

改完点"💾 保存人设"。想恢复默认就点"↩️ 恢复默认人设"。

## 8.5 模型选择

| 模型 | 特点 | 什么时候用 |
| --- | --- | --- |
| `deepseek-chat` | 通用对话，快，便宜 | 日常闲聊 |
| `deepseek-reasoner` | 推理模型，会"想"更久 | 问需要动脑的问题 |

**注意**：`deepseek-reasoner` 会忽略 `temperature` 和 `top_p` 参数。这是模型特性，不是 bug。

## 8.6 上下文轮数

设置 → 🤖 AI 对话 → "携带上下文轮数"（默认 12）。

**这是什么**：每次发消息时，会把它之前记住的对话一起发给 AI。

- 12 轮 = 最近 24 条消息（你一句它一句算一轮）
- 调大 → 它记得更多，但花的 token 更多
- 调小 → 省钱，但它可能"忘了刚才说什么"

## 8.7 多 Key 轮换

如果你有多个 API Key，程序会**自动轮着用**。

**规则**：
- 每次请求换一个 Key
- 401/402/403/404/405/422 这些错误**不重试**（因为重试也没用）
- 网络错误/429/5xx **会重试**，用指数退避（1秒 → 2秒 → 4秒，上限 8 秒）

**为什么要多个 Key**：单个 Key 有速率限制。多个 Key 轮换可以绕过一部分限制。

# 第 9 章　余额提醒与扣钱清单（会花钱的人必看）

## 9.1 余额变了会说话

**默认开启**。第一次启动后，程序每隔 300 秒（5 分钟）查一次你的 DeepSeek 余额。

**查询的是哪个接口**：`GET /user/balance`。**这个接口不消耗 Token**，随便查。

**变了它会说**：
- 少了 → 红字 `▼ 少了 1.20 CNY`
- 多了 → 绿字 `▲ 多了 2.50 CNY`
- 第二行 → `总可用余额 138.22 CNY`

**不吵人的三条规矩**：
1. **第一次成功查询只记基线，不提示**（刚启动就说"少了"很莫名）
2. 变化**小于一分钱**（≤0.005）不提示
3. 查询失败**只写日志**，不弹窗、不动基线

## 9.2 立刻查一次（不等定时器）

三个入口：
- 右键菜单 → 💰 余额与 AI → 🔎 立即查询 DS 余额
- 快捷键 `Ctrl+B`
- 设置 → 🤖 AI 对话 → 🔎 立即查询余额 按钮

**查完一定有回音**：
- 有变化 → 报"少了/多了 + 最新余额"
- **没变化也报** → 灰字"余额没有变化" + 当前余额

**为什么没变化也要报**：以前不报，用户点了按钮什么都没发生，根本不知道查没查。

## 9.3 扣钱清单（余额变化记录）

右键菜单 → 💰 余额与 AI → 📉 扣钱记录…

**这是一个表格窗口**：
```
时间                     变化       变化后余额     来源
2026-09-30 22:13:45.123  -0.03      138.19 CNY    聊天窗口
2026-09-30 22:08:12.456  -0.05      138.22 CNY    定时查询
2026-09-30 21:55:33.789  +2.00      138.27 CNY    手动查询
```

**四列**：
- **时间**：年月日 时:分:秒.毫秒（毫秒 3 位）
- **变化**：扣钱红、进账绿
- **变化后余额**
- **来源**：定时查询 / 手动查询 / **聊天窗口**

**底部汇总**：共几条、扣钱几次共多少、进账几次共多少、最近一次

**按钮**：
- **只看扣钱**（勾选框）
- **🔄 刷新**
- **📄 导出 CSV**（带 UTF-8 BOM + CRLF，Excel 双击不乱码）
- **🧹 清空记录**（会弹确认框）

**记录规则**：
- 只在余额**真的变了**才记（≥0.01）
- **首次只记基线，不记一笔**
- 最多留 **500 条**（超出丢最旧的）

**关于"聊天窗口"这个来源**：一次对话刚结束，程序会**顺手静默查一次**余额。这样你就能在记录里看到"聊天花掉了多少钱"，而不是等下一次定时查询混成一笔。

# 第 10 章　算番 Web 版：手机也能算国标麻将

| `麻将图\` | 43 张牌图 PNG |

## 10.3 怎么用

**步骤 1**：确认设置里"启动桌宠时开启算番 Web 版"是勾上的（默认开）。

**步骤 2**：看地址。右键菜单 → 🧰 工具 → 🀄 算番 Web 版…

窗口里会显示两个地址：
- **本机地址**：`http://127.0.0.1:8718`
- **手机/平板地址**：`http://192.168.1.100:8718`（这是你电脑的局域网 IP）

**步骤 3**：手机连**同一个 WiFi**，浏览器打开那个手机地址。

**步骤 4**：正常算番。算完之后桌宠会冒个气泡说"🀄 合计 N 番"，同时用语音读出来。

## 10.4 端口被占用了怎么办

默认端口 **8718**。被占用时**程序会自动往后找一个**，最多试 20 个。

**技术说明（这是真 bug 修出来的）**：
Python 的 `http.server` 带 `allow_reuse_address=1`（SO_REUSEADDR），**别人监听着的端口照样能绑上**（两个程序抢一个端口，谁也不报错）。

所以"起服务失败就换端口"这个逻辑**永远不触发**。

**正确做法**（v1.1.18 加的）：
1. 先**不带** SO_REUSEADDR 试绑
2. 绑不上再 `connect()` 一下，**真有人在听**才算占用
3. TIME_WAIT 状态的不算占用（那种能绑）

## 10.5 读番是怎么读的

用的是**数字音频拼接**。

`大肥鱼素材表\数字\` 和 `鲸宝音频\` 里放着：
```
1.mp3 ~ 9.mp3
十.mp3 / 百.mp3 / 千.mp3 / 万.mp3 / 十万.mp3 / 百万.mp3 / 千万.mp3 / 亿.mp3
合计.mp3
番.mp3
```

**读法**：`合计` + 数字（拆成片段，一片一片放） + `番`

**例子**：
- 3 番 → 「合计」+「三」+「番」= 3 片
- 24 番 → 「合计」+「二」+「十」+「四」+「番」= 5 片
- 105 番 → 「合计」+「一」+「百」+「零」+「五」+「番」= 6 片

**拆分规则**（中文口语）：
- 10~19 读"十几"，不读"一十几"
- 中间夹零要读（105 读"一百零五"）
- 末尾零不读（120 读"一百二十"）
- 跨"万"补零

**缺哪片跳哪片**。比如没有 `零.mp3`，105 会读成"一百五"。补一个 `数字\零.mp3` 就正了。

## 10.6 连点算番会怎样（v1.1.21 修的）

**以前的问题**：一句"合计一百八十九番"要念 4~6 秒，而用户连点算番时 62% 都在 5 秒内被下一次打断。每次都刚念"合计"就被重头开始，**听着就像没读**。

**现在**：
1. 算番回传 → 气泡**立刻更新**（不等）
2. 番数记成"待念"
3. **停手 0.9 秒**才真的念最后一次

**还有一条**：同一个番数正在念，**就不打断、不重念**。连算同一副牌不会重复念。

## 10.7 读番不出声怎么排查

**三步**：

**① 有没有触发？** 看 `pet_data\logs\` 里的日志。会写"开始读番数：合计二十四番（5 片：合计.mp3、2.mp3、十.mp3、4.mp3、番.mp3）"

**② 有没有出声？** 打开算番窗口点"🔊 试读「88 番」"。

**③ 有没有被掐断？** 如果日志里有"这一轮一片都没播出来，重试一次"，说明音频后端没接上。

**真 bug 的历史（v1.1.19 修的）**：
Qt 的 `QMediaPlayer` 在 **`stop()` 与 `setSource()` 时都会通过 `mediaStatusChanged` 甩出一个属于"上一片"的 `EndOfMedia`**。

旧代码收到就无脑推下一片 → 推掉的是**刚排好的这一片**：
- 单片段数字（1~9 番最常见）直接被推到末尾 → **一声不出**
- 三片数字漏第一片
- 连算两次最容易中招

**修法**：加 `_dfp_armed` 锁。必须见过 `LoadedMedia`/`BufferedMedia`/`PlayingState` 之后才认 `EndOfMedia`。

## 11.3 对话内容加密

**默认开启**。

**加密方案**：
```
密文 = base64( salt(16) | hmac_tag(32) | ciphertext )
key    = PBKDF2-HMAC-SHA256(口令, salt, 120000 次, 32 字节)
流密钥 = SHA256(key || counter_hi64) 依次拼接后截取明文长度
cipher = 明文 XOR 流密钥
tag    = HMAC-SHA256(key, b"dfp1" + salt + cipher)
```

**口令从哪来**：`.env` 的 `DB_PASSWORD`。没设就用默认口令（会写一条 WARNING 日志提醒你换）。

**⚠️ 重要**：**改掉口令后，旧消息会解不开**，会显示"无法解密的消息"。这是设计如此。想换口令请尽早换。

## 11.4 备份

**自动备份**：默认每 60 分钟一次。间隔可调。

**手动备份**：`Ctrl+Shift+S` 或右键菜单 → 🧰 工具 → 💾 立即备份。

**保留份数**：默认 10 份。超出自动删最旧的。

**备份文件长什么样**：
```
pet_data_20261003_221345_自动备份.db
pet_data_20261003_220000_手动备份.db
pet_data_20261003_215500_exit.db
```

**备份用的什么方法**：SQLite 的 `backup()` API，不是直接复制文件。**所以不会丢 WAL 里的数据**。

**还原**：设置 → 🗄️ 数据 → 数据操作里有还原按钮。或者手动把备份文件改名成 `pet_data.db` 覆盖回去（记得先删 `-wal` 和 `-shm`）。

## 11.5 隐私（说清楚，避免误会）

**程序会联网吗**：
- ❌ 不会自动上传任何东西
- ✅ 只有你在聊天窗口发消息时，才把消息发给 DeepSeek
- ✅ 余额提醒是**查询**你的余额，不上传数据
- ✅ 算番 Web 版是**局域网**服务，不连外网

**程序会读你的文件吗**：
- ✅ 只读自己的素材目录（`鲸宝形象\`、`大肥鱼素材表\`、`鲸宝音频\`、`mahjong\`、`数字\`）
- ✅ 只读写自己的数据目录（`pet_data\`）
- ❌ 不扫你的桌面、文档、浏览器历史

**验证方法**：断网跑它，功能除了 AI 聊天之外**全部正常**。

## 11.6 日志里有什么

按天分文件，单文件超 2 MB 自动轮转，最多留 5 份。

**日志级别**：DEBUG / INFO / WARNING / ERROR（可在设置里调）

**控制台噪点日志**（`console_*.log`）单独存：
- Qt 的多媒体后端版本行
- FFmpeg 探测音频时的 `Estimating duration` / `Input #0` / `Metadata`
- `[mp3float] Could not update timestamps for skipped samples`（**这不是错误**，是 FFmpeg 跳过静音帧时的提示）

**想看这些噪点回到控制台**：设 `DFP_VERBOSE=1` 或加 `--verbose`。

## 14.2 铁律（改代码前必读）

项目有 **20 条铁律**，写在第 2~23 行的注释块里。挑最重要的几条：

**铁律 2：文档 + 版本号同步**
改完主程序必须：
① 更新 `软件升级迭代记录.md`（迭代记录/功能清单/代码地图三处）
② 更新主程序第 1 行的 `__version__`
③ 把主程序复制一份到 `version\` 子目录留档

**铁律 5：新增设置项必须三处成对**
- `DFP_DEFAULT_SETTINGS` 加默认值
- `DFPAppController.dfp_on_setting_changed` 加即时生效分支
- 设置窗口用 `_dfp_spin / _dfp_check / _dfp_combo / _dfp_line` 建控件

**铁律 8：窗口摆放一律 `resize + move`**
`setGeometry` 摆的是客户区坐标，而 `x()/y()` 是含标题栏的边框坐标。混用会让窗口每启动一次就上飘一个标题栏高度。

**铁律 9：绝不用一个大 `try/except` 批量给多个 Qt 枚举常量赋值**
必须用 `dfp_enum_value(default, *getters)` 逐个独立求解。否则一个废弃写法会把其它已取到值的常量一起污染成 `None`，导致 `setPen(None)` 这类只在 stderr 报错的隐性崩溃。

**铁律 12：素材相关的兜底 `except` 必须留痕**
不许写成 `except Exception: return None` 就完事。踩过两次血坑：
- `QMovie` 漏在模块顶部 import → `NameError` 被吞 → 表现是"动画永远不动"
- 同名方法重复定义 → 后一份把带素材行为的新实现整段遮掉 → 表现是"自主行为从来不触发"

**铁律 15：桌宠窗口任何时候都要夹在屏幕内**
拖动/走动/跟随/拖拽结束/存盘五处都要过一遍。

**铁律 16：拖拽判定只能用全局鼠标位移**
`mouseMoveEvent` 里绝不能用窗口内局部坐标判"是不是在拖"，因为桌宠会自己走动。

**铁律 17：台词只往 `台词库.json` 里加**
不要写死在代码里。

**教训 77：语音类功能必须拿"一句话多长"对"触发多密"，会来得密就必须节流**

**教训 112：测试里的"真实时间/真实日期/随机"是定时炸弹**

**教训 118："退役"要分开数：声音一条路、形象一条路**

**教训 123：先看清单有没有被程序自己重写过**
"新的好像没生效"有一半是 `素材清单.json` 被程序自己的"重新扫描素材表"重写了。

## 15.2 那四个 `--include-module` 为什么不能少

**2026-10-03 实测踩到的**。

`mahjong\mahjong_api.py` / `mahjong_core.py` 是**运行期**用 `importlib.import_module()` 加载的（dist 里那份松散 `.py`）。`--follow-imports` 看不到它们里面的 import。

⇒ 编译进 exe 的 Python 里没有 `http.server`，日志会写「算番 Web 版没启动：加载 mahjong_api 失败：No module named 'http.server'」，**算番页静默失效**。

**源码运行不受影响，所以只有打包后才看得出来。**

**这四个**：
- `http.server`（连带带出 `socketserver` / `socket` / `urllib.parse` / `email` / `mimetypes` 那一串）
- `socketserver`
- `urllib.parse`
- `argparse`

**为什么不用 `--include-module=mahjong_api`**：那样会把它**编进 exe**，dist 里那份松散 `.py` 就被遮蔽了。而"算番器更新只需替换 `dist\mahjong\` 里的文件、不用重编译"是设计意图。

# 第 16 章　故障排查手册（按现象查）

## 16.1 桌宠不见了 / 点不到

**现象**：桌宠明明在运行，但鼠标点不到它；或者拖到某处后消失了。

**原因**：拖到屏幕外了。用户真实设置里存着 `window_geometry = 1143,-337,220,260`（y 为负数）。

**解决**：
1. 右键托盘图标 → 🪟 窗口 → 🎯 回到屏幕中央
2. 或者按 `Ctrl+Alt+C`
3. 或者按 `Ctrl+H` 先藏起来再显示

**预防**：确保设置里"保持窗口在屏幕内"是开着的（默认开）。

## 16.2 怎么点都摸不到头

**现象**：单击它，它不动、不说话、不冒气泡。

**原因**（v1.1.1 修的老 bug）：拖拽判定用窗口内局部坐标。桌宠自己走动时局部坐标一直在变，手没动也判成拖拽，单击被吞。

**解决**：升级到 v1.1.1 或更新版本。

**验证**：现在的判定用**全局鼠标位移**（≥6 像素才算拖）。而且**一按下就停住走动**。

## 16.3 动画永远不动

**现象**：桌宠只显示一帧，不呼吸、不眨眼。

**原因**（v1.1.0 的老 bug）：`dfp_movie()` 里用了 `QMovie`，但模块顶部**漏了 import** → `NameError` 被 `except Exception: return None` 静默吞掉。

**解决**：升级到 v1.1.0 或更新版本。

**怎么验证**：现在有个专门探针 `probe_asset_motion.py`，逐帧哈希比对，真在动才通过。

## 16.4 自主行为从来不触发

**现象**：设置里开了"偶尔做小动作"，但它永远不做。

**原因**（v1.1.0 的老 bug）：`DFPPetBrain._dfp_check_autonomous_action` 被**定义了两次**。后一份（旧的无素材实现）把前一份（带素材行为的新实现）整段遮掉。**Python 不报错**。

**解决**：升级到 v1.1.0 或更新版本。

**怎么验证**：跑 `probe_undefined_names.py`，它会用 AST 查同名方法重复定义。

## 16.5 气泡里的字不完整

**现象**：气泡显示的字像被剪掉一截。

**原因**（v1.1.8 修的老 bug）：算窗口高度时只留了 24 像素内边距，而画字时又扣掉"尾巴 12 + 边框 1.5 + 上下 8+8 = 29.5"。**恒定少 6 像素**。

中文一行的行高才 16~24 像素，相当于上下各被削掉一截。

**解决**：升级到 v1.1.8 或更新版本。

**验证**：现在量字和画字**共用同一组常量**（`DFP_BUBBLE_TAIL` / `_BORDER` / `_PAD_X` / `_PAD_Y` / `_EXTRA_H`）。绘制还带 `TextDontClip`，宁可溢出也不剪字。

## 16.6 状态面板下面的字看不全

**现象**：状态面板最下面一排按钮被剪掉。

**原因**（v1.1.11 修的老 bug）：`dfp_restore_geometry()` 传的是 `always_center=True`，而那个模式下 `default_geometry` 就是最终尺寸——这里写死 560×520。但内容 `sizeHint` 是 376×627。

**解决**：升级到 v1.1.11 或更新版本。

**验证**：现在内容套在 `QScrollArea` 里，窗口打开时会用 `dfp_needed_size()` 算出来的尺寸。

## 16.7 声音不出来

**排查三步**：

**① 有没有触发？**
看日志。会写"播放语音：voice_poke_5.mp3（poke）"。

**② 有没有出声？**
设置 → 外观 → 形象声音，点试听按钮。

**③ 检查开关**
- "启用形象声音"是不是勾着？
- 对应类别的开关是不是勾着？
- 音量是不是 0？

**如果试听也不出声**：
- 检查系统音量
- 检查有没有音频设备
- 升级到最新版本（v1.1.19 修过 `EndOfMedia` 的 bug）

## 16.8 算番读不出来

**排查**：

**① 有没有触发？**
日志会写"开始读番数：合计二十四番（5 片：合计.mp3、2.mp3、十.mp3、4.mp3、番.mp3）"

**② 音频文件在不在？**
`大肥鱼素材表\数字\` 里应该有 `1.mp3` ~ `9.mp3` + `十/百/千/万/十万/百万/千万/亿.mp3`。
`鲸宝音频\` 里应该有 `合计.mp3` 和 `番.mp3`。

**③ 试读一下**
算番窗口点"🔊 试读「88 番」"。

**④ 看日志**
如果写"这一轮一片都没播出来，重试一次"，说明音频后端没接上。多试几次。

## 16.9 素材清单被写坏了

**现象**：表情从 9 条变成 16 条，或者形象变成 0 条，或者动作片少了。

**原因**：`素材清单.json` 被程序自己的"重新扫描素材表"重写了。

**v1.1.36 修了四处**：

| 症状 | 根因 | 修法 |
| --- | --- | --- |
| 形象图全变静态、待机不动 | `keep_old()` 把 `file` 与 `gif` 两个字段一起写成当前文件 | 新增 `path_fields` 参数，只更新这次处理的字段 |
| 基础形象选项空了 | 3 张基础形象住在 `类别\` 里，全被归到 `faces` | 扫完把 3 条回填进 `characters` |
| "本机语音 93 条" | 兜底扫描把素材包里的 wav 写进清单 | 扫描不再把音频写进清单 |
| 表情突然多出 `['grab']` | `素材6\原始图（带背景）\在床上被抓住左手1.png` 命中"抓"关键字 | 新增"忽略目录词"名单 |

**解决**：升级到 v1.1.36 或更新版本。

## 16.10 睡觉时画的是旧鲸鱼

**原因**：v1.1.15 的"形态覆盖层"——睡觉/忙/等/休息/庆祝/出错时画**素材5 的 7 张 SVG**（旧鲸鱼）。它画在**一切之上**。

**解决**：升级到 v1.1.36 或更新版本。

**v1.1.36 改了什么**：
- 六个状态全改成画**新形象集里的图**
- 旧素材5 的 7 张 SVG 退役到 `素材5\assets\_退役_forms\`（只搬不删）
- 程序**删掉了 SVG 的扫描与渲染**（`dfp_svg_pixmap` / `_dfp_draw_form` / `DFP_FORM_DIRS` 全部移除）
- 旧鲸鱼**没有任何复现路径**

## 16.11 程序启动后命令行刷屏

**原因**：Qt/FFmpeg 的日志没被过滤。

**v1.1.10 修了**：
- 关掉 Qt 多媒体后端的 info 日志
- 装 Qt 消息过滤器
- **接管 stderr（fd 2）**（因为 FFmpeg 是绕开 Qt 直接写 fd 2 的）

**想看回来**：`set DFP_VERBOSE=1` 再跑。

## 16.12 exe 启动后算番 Web 版失效

**原因**：编译时漏了那四个 `--include-module`。

**解决**：看 15.2 节。

## 16.13 数据库打不开

**现象**：日志写"数据库打开失败"。

**可能原因**：
- 程序目录没有写入权限（装在 `C:\Program Files\` 了）
- 数据库文件被别的程序占着
- 磁盘满了

**解决**：
1. 把程序挪到 `D:\` 或 `C:\Users\你的用户名\` 下面
2. 程序会自动退到 `%APPDATA%\DeepSeekFishPet\pet_data\`

## 16.14 消息显示"无法解密的消息"

**原因**：你改过 `.env` 里的 `DB_PASSWORD`。

**解决**：
- 改回原来的口令
- 或者接受这些消息解不开了（这是设计如此）

## 16.15 单实例提示

**现象**：启动时提示"已在运行"。

**原因**：程序用 `QLocalServer`/`QLocalSocket` 实现单实例。第二次启动会把已有桌宠显示出来。

**解决**：不用管，点一下它就会出来。

# 第 19 章　常见问题 100 问

## 安装与启动

**Q1：需要什么系统？**
Windows 10 或 11。打包后不需要 Python 环境。

**Q2：Mac / Linux 能用吗？**
理论上能（PySide6 跨平台），但没测过。`os.startfile()` 这些是 Windows 专用的。

**Q3：装在哪个目录最好？**
有写入权限的地方，比如 `D:\桌宠\`。别放 `C:\Program Files\`。

**Q4：要装 Python 吗？**
用 exe 不用。从源码跑要 Python 3.10+。

**Q5：依赖多吗？**
只有两个：`PySide6` 和 `requests`。

**Q6：为什么启动后命令行是黑的？**
故意的，控制台安静模式。想看日志设 `DFP_VERBOSE=1`。

**Q7：可以开多个桌宠吗？**
不行，单实例。第二次启动会把已有的叫出来。

**Q8：启动很慢是正常的吗？**
第一次启动会扫素材表，慢一点。之后有缓存就快了。

**Q9：启动画面能换吗？**
能。放一个 `启动图.png` 到 `鲸宝形象\` 里。

**Q10：能开机自启吗？**
程序本身没做。你可以把快捷方式丢进"启动"文件夹。

## 日常使用

**Q11：怎么喂它？**
右键 → 🐾 互动 → 🐟 投喂小鱼干。

**Q12：它饿了会自己说吗？**
会。饱食度 ≤25 就喊饿。

**Q13：它会自己睡觉吗？**
默认不会。要开"到点自动睡觉"。

设置里"跟着鼠标跑"默认是关的。

**Q16：它能记住我把它放哪了吗？**
能。"记住上次的位置"默认开着。

**Q17：我不小心把它拖到屏幕外了怎么办？**
`Ctrl+Alt+C` 回到屏幕中央。

**Q18：怎么改它的名字？**
设置 → 🎨 外观 → 昵称。

**Q19：怎么改它的大小？**
滚轮，或者设置里的"大小倍数"。

能。设置里的"不透明度"，最低 0.15。

5 套。但只在"只用代码绘制"模式下生效。

**Q22：为什么换配色没反应？**
因为你在素材模式。素材模式用的是素材图，不吃配色。

见附录 B。

**Q69：三魂七魄是什么？**
十条魂魄，各自"管什么"。出生命盘终身不变。

**Q70：道是什么？**
修真层。道行/心性/元神/五脏六腑/气血/命运数/因果业缘/神仙鬼妖。

**Q71：这些会影响数值吗？**
**不会**。它们是"表达层"，不动饱食/精力/经验/亲密度。

**Q72：能关掉修真层吗？**
能。设置里的"让她修"。

## AI 聊天

**Q73：必须配 API Key 吗？**
不必须。不配就是离线模式，说话用内置台词库。

**Q74：Key 写在哪？**
`.env` 文件。或者在设置窗口里填。

**Q75：Key 会存到设置文件里吗？**
**不会**。只存 `.env`。

**Q76：能用多个 Key 吗？**
能。逗号分隔，自动轮换。

**Q77：Key 无效怎么办？**
401 错误。检查 Key 是不是复制错了。

**Q78：余额不足怎么办？**
402 错误。去 DeepSeek 官网充值。

**Q79：能用自己的接口吗？**
能。改 `.env` 里的 `DEEPSEEK_API_BASE`。

**Q80：能改人设吗？**
能。设置 → 🤖 AI 对话 → 最下面的大文本框。

**Q81：上下文轮数怎么调？**
设置里的"携带上下文轮数"，默认 12。

**Q82：上下文越大越贵吗？**
是的。每轮都会一起发过去。

**Q83：能让它只说一句话吗？**
设置里的"气泡最多念"，默认 60 字。

**Q84：对话记录能导出吗？**
能。4 种格式：Markdown / 文本 / JSON / 网页。

**Q85：对话会加密吗？**
默认加密。口令在 `.env` 的 `DB_PASSWORD`。

**Q86：改了口令会怎样？**
旧消息解不开，显示"无法解密的消息"。

**Q87：余额提醒会花 token 吗？**
不会。`/user/balance` 接口不消耗 Token。

**Q88：扣钱记录能导出吗？**
能。CSV 格式，带 BOM，Excel 双击不乱码。

**Q89：扣钱记录留多少条？**
500 条。超出丢最旧的。

**Q90：为什么有"聊天窗口"这个来源？**
因为一次对话刚结束会顺手静默查一次，这样就能单独看到聊天花了多少。

## 算番

**Q91：算番 Web 版怎么用？**
见第 10 章。

**Q92：手机怎么连？**
同一个 WiFi，浏览器打开电脑的局域网 IP。

**Q93：端口被占用怎么办？**
自动往后找。最多试 20 个。

**Q94：读番为什么读错？**
可能缺 `零.mp3`。105 会读成"一百五"。

**Q95：能读 0 番吗？**
能。读"零"。

**Q96：连点算番会怎样？**
停手 0.9 秒才念最后一次。

**Q97：同一个番数会重复念吗？**
不会。正在念就不打断。

**Q98：算番器能改吗？**
能改源项目 `G:\Python_Code\Mahjong_Calculator`，然后重拷。

**Q99：麻将图在哪？**
`mahjong\麻将图\`。

**Q100：算番功能能关吗？**
能。设置 → 🀄 算番 → 关掉"启动桌宠时开启算番 Web 版"。

```json
  ],
  "animations": [
    { "id": "diaoyu", "label": "钓鱼", "category": "玩耍", "gif": "…/diaoyu.gif", "frames": 120, "size": [220, 124] }
  ],
  "faces": [
    { "id": "love_heart", "label": "胸前比心", "file": "…", "gif": "…", "face_of": ["love"], "category": "交互", "source": "类别" }
  ],
  "voices": [],
  "memes": [],
  "icons": [],
  "prompt_headings": [],
  "counts": { "characters": 3, "faces": 78, "expressions": 0, "animations": 0, "voices": 0 }
}
```

| 字段 | 约定 |
| --- | --- |
| `manifest_version` | v1.1.35 起是 2 |
| `characters[].file` | 立绘 PNG，**数组第一个就是默认形象** |
| `expressions[].id` | 固定 9 个关键字之一：`blink` / `smile` / `wave` / `yawn` / `sleepy` / `wakeup` / `grab` / `heart` / `shake` |
| `animations[].category` | 七类之一：`交互` / `吃喝` / `休息` / `工作` / `节日` / `碎碎念` / `玩耍` |
| `animations[].gif` | **推荐用 GIF**：素材里的 `.webm`（HEVC + alpha）**Qt 解不了** |
| `faces[].id` | 文件名去掉前导编号 |
| `faces[].face_of` | 服务哪些台词类别 |
| `faces[].category` | 中文行为分组 |
| `voices[].category` | 固定四类：`ask` / `confirm` / `done` / `poke` |
| `voices[].text` | 可选的人工台词 |
