## 新增语音的流程

1. 从上面挑句子（**带 ★ 的都是 ≤15 字、录 1.5~2.5 秒就够的**）；
2. 录好后命名 `voice_<类别>_<序号>.<扩展名>`，类别目前支持 `poke` / `confirm` / `ask` / `done`，
   支持 `.mp3 / .wav / .ogg / .m4a`，丢进 `鲸宝音频\`（★ v1.1.30 起**所有录音都在这里**；分不分类别子目录都行）；
3. 台词写进同目录的 `语音台词.json`（跑 `_scaffold\export_lines.py` 会自动补上）；
4. 想立刻听到：右键菜单「🔄 重新扫描素材表」（`鲸宝音频\` 每次载入实时扫描，通常不用点）；
5. 想加**新类别**（例如 `hungry` 饿肚子），需要同时改程序里的 `DFPVoicePlayer` 类别开关与触发点，跟我说一声即可。

> 时长可随时用 `_scaffold\probe_voice_duration.py` 复量；台词与语音的对照表见 `语音台词表.md`。

## 想直接改台词？改 `台词库.json`

`大肥鱼素材表\台词库.json` 是程序运行时**优先读取**的台词库，结构：

```json
{
  "mode": "replace",       // replace（默认）：这里出现的类别整个取代内置；merge：追加到内置后面（按内容去重）
  "drop_missing": false,   // true：这里没有的类别直接删掉（完全以本文件为准）
  "lines": { "greet": ["…", "…"], "hungry": ["…"] },
  "level_titles":   [[1, "刚认识的小鱼"]],   // 可选
  "time_greetings": [[5, 11, "morning"]]      // 可选，[起始小时, 结束小时, 类别]
}
```

改完在桌宠右键菜单点「📜 重新载入台词库（台词库.json）」（设置窗口同款按钮）即可生效，**不用重启**。
文件读坏了不会崩：程序会退回内置台词，并在设置窗口里把出错原因显示出来。
