## 填完之后可以怎么用（告诉我要哪个就行）

1. **气泡字幕**：播语音时把台词显示在桌宠的气泡里（相当于字幕）。可以和现在的离线台词库错开，
   避免「说的和显示的不一样」；
2. **界面提示**：设置窗口里 4 个「试听」按钮、状态面板的试听按钮旁显示台词 + 时长，挑声音不用猜；
3. **语音日志**：日志里记「播放 voice_poke_2.mp3（台词：…）」；
4. **只做备注**：仅写进 `素材清单.json`，界面不显示。

## 附：想加新语音怎么办

1. 文件放进 `大肥鱼素材表\素材2\assets\`（放别的子目录也会被扫到），支持 `.mp3 / .wav / .ogg / .m4a`；
2. 命名规则：`voice_<类别>_<序号>.<扩展名>`，类别只认 **poke / confirm / ask / done**（别的会落到 `other`、不会被播）；
3. 然后点右键菜单「🔄 重新扫描素材表」（或跑 `_scaffold\build_asset_manifest.py`）即可生效，
   同类语音越多，随机挑到的变化越多；
4. 加完可以在这张表里补一行，时长用 `_scaffold\probe_voice_duration.py` 再量一次。
